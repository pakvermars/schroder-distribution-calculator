# 키움슈로더월지급펀드 분배금 계산기

기준가와 매입금액을 넣으면 월·연 분배금과 매입금액 대비 분배율을 세전·세후로 계산합니다.

**바로 사용하기:** https://pakvermars.github.io/schroder-distribution-calculator/

## 파일

| 파일 | 설명 |
|---|---|
| `index.html` | 웹 계산기 (GitHub Pages로 공개) |
| `슈로더 월분배금 계산기.xlsx` | 같은 계산을 하는 엑셀 파일. 노란 칸만 입력하면 자동 계산 |

## 계산식

- 매입좌수 = 매입금액 ÷ 기준가 × 1000
- 월 분배금 = 매입좌수 ÷ 1000 × 1,000좌당 월분배금
- 분배율(연) = 1,000좌당 월분배금 × 12 ÷ 기준가
- 세후 = 세전 × (1 − 배당소득세율 15.4%)

## 유의사항

비공식 개인 계산기이며 운용사·판매사와 관계없고, 투자 권유가 아닙니다. 월 분배금은 운용사가 정하므로 바뀔 수 있습니다. 세금은 15.4% 일반과세 기준이며, 금융소득종합과세 대상자나 절세계좌는 실제 금액이 다릅니다.
